# Smart Garage Meter - Phase 1 Architecture Freeze

Status: LOCKED

Highlights:
- ESP32-C3 SuperMini
- INA226 + external 100A/75mV shunt
- 8-30V input
- Battery Engine with coulomb counting
- Offline First
- Modular architecture
- Hardware First
- Layered firmware architecture
- Display, AUX I2C, 1-Wire and VE.Direct interfaces
- Expandable design
